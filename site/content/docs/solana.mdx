**Example**

```bash
curl https://api.chain-rpc.online/solana \
  -X POST -H "Content-Type: application/json" \
  -H "x-api-key: test" \
  -d '{ "jsonrpc": "2.0", "id": 1,
    "method": "getBalance",
    "params": ["83astBRguLMdt2h5U1Tpdq5tjFoJ6noeGwaY3mDLVcri", { "commitment": "finalized" }]
}'
```
