In order for a software application to interact with a blockchain—whether to read blockchain data 
or send transactions to the network—it must connect to a node within the blockchain’s peer-to-peer (P2P) network. 
To standardize this interaction, many blockchain clients implement a JSON-RPC specification, providing a consistent set of methods 
that applications can use, regardless of the specific client or node implementation.

### Supported Networks

| Network | RPC URL | Protocol
| --- | --- | --- |
| TON | https://api.chain-rpc.online/ton | JSON-RPC, REST 
| Bitcoin | https://api.chain-rpc.online/bitcoin | JSON-RPC, REST (Index Only)
| Ethereum | https://api.chain-rpc.online/ethereum | JSON-RPC
| Monero | https://api.chain-rpc.online/monero | JSON-RPC
