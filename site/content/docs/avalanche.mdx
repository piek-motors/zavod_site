JSON RPC Endpoint: https://api.chain-rpc.online/avalanche \

curl example
```bash
curl https://api.chain-rpc.online/avalanche \
  -X POST -H "Content-Type: application/json" \
  -H "X-API-Key: test" \
  -d '{ "jsonrpc": "2.0", "id": 1,
    "method": "eth_blockNumber",
    "params": []
}'
```
