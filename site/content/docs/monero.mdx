title: Monero Node RPC
description: Engage with the Monero RPC API to access XMR blockchain data, manage transactions, check balances, and retrieve block information securely while maintaining privacy-focused development.
---

JSON RPC Endpoint: https://api.chain-rpc.online/monero

<b>curl example</b> \
```bash
curl https://api.chain-rpc.online/monero \
  -X POST -H "Content-Type: application/json" \
  -H "X-API-Key: test" \
  -d '{ 
    "jsonrpc": "2.0", "id": 1,
    "method": "get_info"
}'
```
