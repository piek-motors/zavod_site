  Its emphasis on fungibility, decentralization, and user anonymity makes it a leading choice for secure digital payments.
---
JSON RPC Endpoint: https://api.chain-rpc.online/monero

<b>curl example</b> \
```bash
curl https://api.chain-rpc.online/monero \
  -X POST -H "Content-Type: application/json" \
  -H "X-API-Key: test" \
  -d '{ 
    "jsonrpc": "2.0", "id": 1,
    "method": "get_info"
}'
```
